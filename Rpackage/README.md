# Serial implementation (R package)

- `DoAggregate/`: the R package. See [DoAggregate/README.md](DoAggregate/README.md) for installation and usage.
- `dependencies/`: source tarballs of `RVtests` 1.2 (not available on CRAN) and `glmnet` 4.1-8.
- `examples/run_DoAggregate_examples.R`: runs the package on the public test datasets of this repository.
